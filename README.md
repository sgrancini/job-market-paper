## Publish a new version

After compiling the canonical source PDF, double-click:

`/Users/stefanograncini/Desktop/WORK/Job Market/Publish JMP.command`

The publisher validates the source, replaces `paper.pdf`, updates the landing-page date, commits the change, and pushes it to GitHub. The public URLs stay the same.

To run the same process manually in Terminal:

```sh
"/Users/stefanograncini/Desktop/WORK/Job Market/job-market-paper/update_paper.sh"
```

Past versions remain recoverable from this repository's Git history.
